# Oda Frame — Memórias em Foco

> "Onde o olhar encontra o essencial"

Oda Frame é uma aplicação web para guardar e organizar suas memórias fotográficas. O usuário faz upload das suas fotos, classifica por tipo (viagens, família, amigos...) e pelo sentimento do momento, e pode acompanhar tudo através de um dashboard com gráficos e estatísticas.

---

## Por que esse projeto existe?

A ideia surgiu da vontade de criar um espaço onde lembranças deixam de estar dispersas e passam a existir com intenção. Mais do que um álbum, o Oda Frame permite enxergar padrões nos seus momentos: qual tipo de foto você mais registra? Em qual mês você mais fotografa? Qual emoção aparece com mais frequência?

---

## O que o sistema faz

- Cadastro e login de usuários
- Upload de fotos com data, tipo e sentimento
- Galeria pública na página inicial
- Dashboard com gráficos e KPIs calculados automaticamente

---

## Tecnologias

| Camada | Tecnologia |
|--------|-----------|
| Servidor | Node.js + Express |
| Banco de dados | MySQL (hospedado na VM) |
| Upload de arquivos | Multer |
| Gráficos | Chart.js |
| Frontend | HTML, CSS e JavaScript |
